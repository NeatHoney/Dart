# Relación 2 - Ejercicios de Dart con funciones

Ejercicios de la relación II de Dart (Programación multimedia y de dispositivos móviles, IES Playamar), centrada en funciones.

## Contenido

| Ejercicio | Archivo | Tema |
|---|---|---|
| 1 | `1fecha-hora-dart.dart` | Función sin parámetros ni retorno (fecha y hora actuales) |
| 2 | `2fecha-hora-desplazada-dart.dart` | Función con parámetro, `DateTime.add` |
| 3 | `3parametros-opcionales-dart.dart` | Parámetros con nombre y valores por defecto |
| 4 | `4parametro-nullable-dart.dart` | Parámetro posicional opcional nullable |
| 5 | `5fecha-hora-retorno-dart.dart` | Función que devuelve un `DateTime` |
| 6 | `6suma-naturales-dart.dart` | Suma de los n primeros naturales |
| 7 | `7factorial-dart.dart` | Factorial |
| 8 | `8mcd-dart.dart` | MCD con el algoritmo de Euclides |
| 9 | `9cociente-resto-dart.dart` | Cociente y resto (+ preguntas sobre SRP) |
| 10 | `10binario-dart.dart` | Conversión a binario y a bases hasta 8 |
| 11 | `11temperaturas-dart.dart` | Máxima, mínima y media de una lista |
| 12 | `12temperaturas-map-dart.dart` | Lo mismo con un `Map` |
| 13 | `13es-primo-dart.dart` | Función `esPrimo` |
| 14-17 | `14...` a `17...-recursivo-dart.dart` | Versiones recursivas de los ejercicios 6-9 |
| 18 | `18fibonacci-dart.dart` | Serie de Fibonacci en una lista |
| 19 | `19primos-hasta-n-dart.dart` | Lista de primos hasta n |
| 20 | `20temperaturas-dart.dart` + `20temperaturas_lib.dart` | Librería de funciones importada |

## Ejecución

```
dart run 8mcd-dart.dart
```
